    About these images

    Every frame on this page is a flat placeholder generated in CSS and SVG, not a photograph, and nothing here is hotlinked from anywhere else. The filename printed on each frame is what the site expects: drop a real photograph in the images/ folder under that name and it will appear with no other changes. Keep the aspect ratio roughly as shown so the layout does not shift, and keep files under about 300 KB so the page stays fast.

    If you are using other people's photographs, use your own, ones you have permission for, or images released under a licence that allows it — and credit the photographer in the caption. There is a full list of expected filenames in images/README.md.
